# GS12 Form

เว็บสำหรับกรอกแบบฟอร์ม GS12 ของมหาวิทยาลัยทักษิณ พัฒนาขึ้นเพื่อให้สามารถกรอกข้อมูลลงในแบบฟอร์มผ่านหน้าเว็บได้ โดยไม่ต้องกรอกหรือแก้ไขไฟล์ PDF โดยตรง

ระบบจะแสดงแบบฟอร์ม GS12 ต้นฉบับและให้ผู้ใช้กรอกข้อมูลในตำแหน่งที่กำหนด เมื่อกรอกข้อมูลเรียบร้อยแล้วสามารถ Export แบบฟอร์มออกมาเป็นไฟล์ PDF ที่พร้อมใช้งานได้

## Technology

* HTML
* CSS
* JavaScript
* PDF.js
* jsPDF
* Vercel
